[Crush](https://github.com/charmbracelet/crush) is Charm's glamorous open-source AI coding agent for your terminal. Connecting it to betarouter takes a single provider entry in Crush's config — and gives you access to 200+ models from 40+ providers through one API key, with every request tracked in your dashboard.

## Prerequisites

- Crush installed:

  ```bash
  # Homebrew
  brew install charmbracelet/tap/crush

  # NPM
  npm install -g @charmland/crush
  ```

  See the [Crush README](https://github.com/charmbracelet/crush#installation) for Windows, Arch, Nix, and FreeBSD instructions.

- An betarouter API key — [sign up](https://betarouter.com/signup) and create one from your dashboard

## Setup

<Steps>
<Step>
### Set Your API Key

Export your betarouter API key in your shell:

```bash
export BETA_GATEWAY_API_KEY=beta_your_api_key_here
```

Add it to your shell profile (`~/.zshrc` or `~/.bashrc`) to make it permanent.

</Step>

<Step>
### Add betarouter as a Provider

Create a `crush.json` in your project directory (or `~/.config/crush/crush.json` for a global setup):

```json
{
	"$schema": "https://charm.land/crush.json",
	"providers": {
		"betarouter": {
			"name": "betarouter",
			"type": "openai-compat",
			"base_url": "https://api.betarouter.com/v1",
			"api_key": "$BETA_GATEWAY_API_KEY"
		}
	}
}
```

Crush auto-discovers all available models from betarouter's `/v1/models` endpoint, so there is no model list to maintain.

</Step>

<Step>
### Start Coding

Launch Crush:

```bash
crush
```

Select "betarouter" from the provider list, pick a model, and start building. You can switch models at any time from within Crush.

</Step>
</Steps>

## Locking to a Specific Provider

By default, betarouter automatically fails over to alternative providers if your chosen provider is experiencing downtime. If you want to lock into a specific provider/model mapping — for example to guarantee a fixed price or to always use a single provider — add the `X-No-Fallback` header to your provider entry:

```json
{
	"$schema": "https://charm.land/crush.json",
	"providers": {
		"betarouter": {
			"name": "betarouter",
			"type": "openai-compat",
			"base_url": "https://api.betarouter.com/v1",
			"api_key": "$BETA_GATEWAY_API_KEY",
			"extra_headers": {
				"X-No-Fallback": "true"
			}
		}
	}
}
```

<Callout type="warn">
	Disabling fallback means requests will fail if the chosen provider is down.
	See the [routing docs](/features/routing) for details.
</Callout>

## Troubleshooting

### 401 Unauthorized

Verify `BETA_GATEWAY_API_KEY` is exported in the shell where you launch Crush and that the key is active in your [dashboard](https://betarouter.com/dashboard).

### 404 Not Found

Verify your `base_url` is set to `https://api.betarouter.com/v1` (note the `/v1` at the end).

### Models not showing up

Model discovery runs when Crush starts — restart Crush after adding or changing the provider config.
